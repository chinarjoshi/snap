When did the world unanimously concede to buttons as an acceptable way to operate software? When I'm sweaty and tired the last thing I want is to navigate some overengineered dilute AI-slop. So here's some overengineered concentrated AI-slop:

You type plain text. You hit enter twice. If the paragraph has semantic meaning, like a workout, a recipe, anything, SNAP parses it into a typed result. If not, nothing happens.

One interface across platforms. Tree-sitter grammars compile to C. Swift (iOS) and Emacs call the same parser, get the same results.

#+begin_src swift
import Snap

let result = snap("squat 3x8x225")
// .workout(WorkoutResult(exercises: [Exercise(name: "Squat", ...)]))

let result = snap("chicken biryani:\n1 tbsp jeera\n1 bay leaf")
// .recipe(RecipeResult(title: "Chicken Biryani", sections: [...]))

let result = snap("just a normal paragraph")
// nil
#+end_src

#+begin_src elisp
(snap-workout "squat 3x8x225")   ;; => alist or nil
(snap-recipe "biryani:\n1 cup rice\n1 tsp salt") ;; => alist or nil
#+end_src

** Current Parsers

*** Workout

| Notation                          | Meaning                                |
|-----------------------------------+----------------------------------------|
| =squat 225=                       | 1 set of 8 reps @ 225                  |
| =squat 8 8 225=                   | 2 sets of 8 reps @ 225                 |
| =squat 3x8x225=                   | 3 sets of 8 reps @ 225                 |
| =squat 3x8 225=                   | 3 sets of 8 reps @ 225                 |
| =squat 8 by 225=                  | 3 sets of 8 reps @ 225                 |
| =squat 3 by 8 by 225=             | 3 sets of 8 reps @ 225                 |
| =squat 135 135 135=               | 3 sets of 8 reps @ 135 (default reps)  |
| =dips 8 8 8=                      | 3 bodyweight sets                      |
| =squat 8x135 bench 8x95=          | multiple exercises on one line         |
| =dips* press* 8 135 8 135 8 135=  | superset, alternating sets             |
| =Bench\n8x135\n8\n8=              | multi-line, weight carries over        |
| =squat 8 8 135 felt heavy 8=      | inline note attached to second set     |

*** Recipe

#+begin_example
chicken biryani:
chicken marinade:
1 tbsp jeera
1 bay leaf
3-5 pieces cardamon
8 cloves
1 tsp turmeric
rice water:
2 cups rice
Less salt in rice BUT STILL SALT IT
Add some water to the curry
Cook for 8 min med-high, then 10 mins low
#+end_example

- First line ending with =:= is the title
- Subsequent lines ending with =:= start named sections
- Lines starting with a number are ingredients (quantity + text)
- =3-5 pieces= is a range quantity
- Everything else is an instruction or note
- No sections needed — =smoothie:\n1 banana\n2 cups milk= works fine

** Structure

#+begin_example
grammars/workout/    # tree-sitter grammar
grammars/recipe/     # tree-sitter grammar
lib/                 # C parsers (shared by all platforms)
vendor/tree-sitter/  # tree-sitter runtime (submodule)
swift/               # Swift wrapper + tests
emacs/               # Emacs dynamic module
#+end_example

** Adding a Parser

1. Write =grammars/<type>/grammar.js=, run =tree-sitter generate=
2. Write =lib/<type>.c= + =lib/<type>.h=
3. Add Swift wrapper in =swift/Sources/Snap/=
4. Add =.type(TypeResult)= case to =SnapResult=
5. Register C function in =emacs/snap.c=
