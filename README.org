SNAP (Structured Note Auto-Parsers). Domain-specific parsers that turn natural language into structured data. Each parser takes a paragraph of plain text and returns a typed result or nil. All parsing logic is in C via tree-sitter, with thin wrappers for Swift (iOS) and Emacs.

** Workout Parser

Parses natural workout descriptions into structured exercise data.

*** Example

Input:
#+begin_example
squat 8 8 8 225
bench 3x8 155
#+end_example

Output: =WorkoutResult= with exercises and prose lines.

*** Syntax

| Notation         | Meaning                        |
|------------------+--------------------------------|
| =squat 225=      | 1 set of 8 reps @ 225          |
| =squat 8 8 225=  | 2 sets of 8 reps @ 225         |
| =squat 3x8 225=  | 3 sets of 8 reps @ 225         |
| =squat 3x8x225=  | 3 sets of 8 reps @ 225         |
| =squat 8 by 225= | 3 sets of 8 reps @ 225         |

** Swift

#+begin_src swift
dependencies: [
    .package(path: "path/to/snap")
]
#+end_src

#+begin_src swift
import SnapParsers

let result = parse("squat 3x8 225")
// result: WorkoutResult?
#+end_src

** Emacs

#+begin_src bash
cd emacs && make
#+end_src

#+begin_src elisp
(add-to-list 'load-path "/path/to/snap/emacs")
(require 'snap)
(snap-workout-parse "squat 3x8 225")
#+end_src

** Structure

#+begin_example
grammars/workout/    # tree-sitter grammar + generated parser
lib/                 # C domain logic
vendor/tree-sitter/  # vendored tree-sitter runtime
swift/               # Swift wrapper + tests
emacs/               # Emacs dynamic module
#+end_example

** Adding a Parser

1. Write =grammars/<type>/grammar.js=, run =tree-sitter generate=
2. Write =lib/<type>.c= + =lib/<type>.h= (C domain logic)
3. Add Swift wrapper in =swift/Sources/SnapParsers/=
4. Register C function in =emacs/snap.c=
