# Workout Log Parser Design

A PEG parser for workout logs written in natural language, producing structured tables.

## Overview

Parse freeform workout logs like:
```
squat 8 8 8 135 light headed. leg press 8 315 7 250 7. bench 135 super hard 135 125 115
```

Into structured output:
```
|            | Set 1          | Set 2     | Set 3     | Set 4   |
|------------|----------------|-----------|-----------|---------|
| Squat      | 8 @ 135 (lh)   | 8 @ 135   | 8 @ 135   |         |
| Leg Press  | 8 @ 315        | 7 @ 250   | 7 @ 250   |         |
| Bench      | 8 @ 135 (sh)   | 8 @ 135   | 8 @ 125   | 8 @ 115 |
```

## Parsing Rules

| Rule | Description |
|------|-------------|
| Number ≤20 | Reps |
| Number >20 | Weight (always lbs) |
| Default reps | 8 |
| Default sets (by-syntax only) | 3 |
| `NxM` | N sets of M reps |
| `NxMxW` | N sets of M reps @ W weight |
| `R by W` | 3 sets of R reps @ W |
| `S by R by W` | S sets of R reps @ W |
| Trailing reps | Inherit previous weight |
| Text before first number | Exercise name (normalized to title case) |
| Text after numbers | Note (attaches to preceding set) |
| Period or newline | Exercise delimiter |
| Padding | Empty cells for exercises with fewer sets |

## Data Structures

```go
// Set represents a single set within an exercise
type Set struct {
    Reps   int
    Weight int
    Note   string // optional, empty if none
}

// Exercise represents a parsed exercise with all its sets
type Exercise struct {
    Name string
    Sets []Set
}

// WorkoutLog represents the complete parsed workout
type WorkoutLog struct {
    Exercises []Exercise
    MaxSets   int // for table padding
}

// Table returns a 2D representation for display
// First column is exercise name, remaining columns are sets
func (w *WorkoutLog) Table() [][]string
```

## PEG Grammar (pigeon)

```peg
{
package parser

func toInt(s string) int { ... }
func classifyNumber(n int) string { ... } // "reps" or "weight"
func titleCase(s string) string { ... }
}

Input <- exercises:ExerciseList EOF {
    return exercises, nil
}

ExerciseList <- first:Exercise rest:(Delimiter Exercise)* {
    // Collect all exercises into []Exercise
}

Delimiter <- [.\n]+

Exercise <- name:ExerciseName sets:SetData* {
    // Build Exercise{Name: titleCase(name), Sets: sets}
}

ExerciseName <- chars:(!Number .)+ {
    // Everything before first number, trimmed
}

SetData <- Multiplier / ByExpression / NumberSequence / Note

Multiplier <- sets:Number [xX] reps:Number weight:([xX] Number)? {
    // 3x8 or 3x8x135
}

ByExpression <- first:Number _ "by" _ second:Number third:(_ "by" _ Number)? {
    // 8 by 35 → (default 3) x 8 @ 35
    // 2 by 8 by 35 → 2 x 8 @ 35
}

NumberSequence <- n:Number {
    // Classify as reps (≤20) or weight (>20)
    // Track state to pair reps with weights
}

Note <- text:NoteText {
    // Attach to preceding set
}

NoteText <- (!Number !Delimiter .)+

Number <- digits:[0-9]+ { return toInt(string(digits)) }

_ <- [ \t]*
```

## Parser State Machine

The parser needs internal state to handle contextual rules:

```go
type parseState struct {
    currentExercise  string
    sets             []Set
    pendingReps      int      // reps waiting for a weight
    lastWeight       int      // for trailing reps inheritance
    defaultReps      int      // 8
    defaultSets      int      // 3
}
```

### State Transitions

1. **See reps (≤20):** Store in `pendingReps`, wait for weight
2. **See weight (>20):**
   - If `pendingReps > 0`: create set with pendingReps @ weight, clear pendingReps
   - If `pendingReps == 0`: create set with defaultReps (8) @ weight
   - Update `lastWeight`
3. **See reps with no following weight:** Use `lastWeight`
4. **See note text:** Attach to most recent set in `sets`
5. **See delimiter:** Finalize exercise, reset state

### Handling "by" Expressions

- `8 by 35` → `pendingReps=8`, weight=35, expand to `defaultSets` (3) sets
- `2 by 8 by 35` → sets=2, reps=8, weight=35

## Edge Cases

| Input | Interpretation |
|-------|----------------|
| `squat 135` | 3×8 @ 135 (default reps, default sets) |
| `squat 8 135` | 1×8 @ 135 (explicit reps, no set expansion) |
| `squat 8 by 135` | 3×8 @ 135 (by-syntax triggers default sets) |
| `squat 3x8 135` | 3×8 @ 135 (explicit multiplier) |
| `squat 135 135 135` | 3×8 @ 135 (three weights, default reps each) |
| `squat 8 8 8 135` | 3×8 @ 135 (three reps, one weight shared) |
| `squat 8 135 6 135` | 8@135, 6@135 (two different rep counts) |
| `squat 20 21` | 20 reps @ 21lbs (boundary: 20 is reps, 21 is weight) |

### Ambiguity: `squat 8 8 8 135`

Three 8s followed by 135. Resolution: collect all numbers first, then classify. Reps (≤20) without immediate weights "float" until a weight appears or line ends.

## CLI Interface

```go
// cmd/workoutliner/main.go

func main() {
    // Read from stdin or file argument
    input := readInput()

    // Parse
    log, err := parser.Parse(input)
    if err != nil {
        fmt.Fprintf(os.Stderr, "parse error: %v\n", err)
        os.Exit(1)
    }

    // Output as table
    table.Print(log)
}
```

### Usage

```bash
# From stdin
echo "squat 8 8 8 135. bench 5 5 5 185" | workoutliner

# From file
workoutliner workout.txt
```

## Test Cases

```go
func TestParser(t *testing.T) {
    cases := []struct {
        input    string
        expected WorkoutLog
    }{
        // Basic
        {"squat 8 8 8 135", log("Squat", set(8,135), set(8,135), set(8,135))},

        // Weight-only (default reps)
        {"bench 135 125 115", log("Bench", set(8,135), set(8,125), set(8,115))},

        // Multiplier syntax
        {"squat 3x8 135", log("Squat", set(8,135), set(8,135), set(8,135))},
        {"squat 3x8x135", log("Squat", set(8,135), set(8,135), set(8,135))},

        // By syntax
        {"press 8 by 35", log("Press", set(8,35), set(8,35), set(8,35))},
        {"press 2 by 8 by 35", log("Press", set(8,35), set(8,35))},

        // Trailing reps inherit weight
        {"leg press 8 315 7 250 7", log("Leg Press", set(8,315), set(7,250), set(7,250))},

        // Notes
        {"squat 8 135 hard", log("Squat", setNote(8,135,"hard"))},
        {"bench 135 tough 125", log("Bench", setNote(8,135,"tough"), set(8,125))},

        // Multi-exercise
        {"squat 135. bench 185", log("Squat", set(8,135)), log("Bench", set(8,185))},
    }
}
```
